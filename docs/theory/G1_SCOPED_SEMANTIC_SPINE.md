# G1 Semantic Spine And Scoped Necessity Program

This is the paper-facing statement for the current G1 milestone.  It separates
the current semantic spine from older status/readout capstones.

## English

G1 is the scoped necessity program for Structural Persistence Theory.  The
intended role is:

```text
strict observed persistence/collapse calculation
+ same-calculation criterion
-> output F/K/V_K skeleton
-> scoped L/M separation surface
-> aligned generated two-channel traces
```

The current public Lean anchors are:

```lean
currentViewInjective_globalResponseEquiv_forces_scopedAdditiveMLSeparation
g1_scopedInevitabilitySkeleton_of_currentViewSameCalculation
```

Scope is not a retreat from the theorem; it is the object of the theorem.
As a channel model in information theory fixes what counts as the communication
problem, or a state/input model in control theory fixes what counts as the
controlled system, the visible/current-view same-calculation criterion fixes
when two persistence/collapse calculations are being compared as the same
calculation.  Whether that scope is natural for a concrete domain remains a
separate adapter/proxy-certificate obligation.

The first theorem is the visible-state route.  Current-view injectivity on the
source and target supplies extensionality; global current-view response-image
equivalence folds to local current-view equivalence; the target-side scoped
additive `L/M` separation entrance follows.

The second theorem is the folded current-view skeleton surface.  Its
same-calculation input is:

```lean
CurrentViewObservationalSameCalculation
```

This predicate is observation-only and is definitionally equivalent to
current-view fixed action coverage.  Under that scope, plus response
separation, target identity, and matching initial current view, the theorem
constructs source and alternative `CurrentInevitabilitySkeletonInterface`
outputs and proves `SameCurrentSkeletonSurface`.

Safe reading:

```text
For the stated visible/current-view same-calculation scope, the interface is
not supplied as hidden input.  The calculation factors through output
F/K/V_K skeletons, reaches the scoped L/M separation surface, and aligns the
generated two-channel traces.
```

This is the current scoped semantic G1 spine.  It is not:

- scope-free semantic no-alternative for every possible representation;
- automatic adapter discovery from arbitrary hidden-state systems;
- full native `L/B` recovery or qualified-support `M` measurement;
- empirical prediction or world forecasting;
- native theorem reproof in external domains;
- free external-domain transport.

The full research archive contains older status/readout capstones and public
wrappers.  They are useful as audit infrastructure, but they are not included
in this curated core repository and are not the best citation for the current
semantic core.  Prefer the two Lean anchors above when citing G1 proof
substance.

## Japanese

G1 は、構造持続理論における scoped 必然性プログラムである。
現在の役割は次のように読む。

```text
観測された厳密な持続・崩壊計算
+ 同一計算条件
-> 出力としての F/K/V_K skeleton
-> scoped L/M separation surface
-> 生成された二成分 trace の整合
```

現在の公開 Lean アンカーは次である。

```lean
currentViewInjective_globalResponseEquiv_forces_scopedAdditiveMLSeparation
g1_scopedInevitabilitySkeleton_of_currentViewSameCalculation
```

scope は定理からの後退ではなく、定理の対象である。情報理論で channel
model が通信問題を固定し、制御理論で state/input model が制御対象を
固定するのと同じように、visible/current-view same-calculation criterion
は、二つの持続・崩壊計算を「同じ計算」として比較してよい条件を固定する。
その scope が具体ドメインにとって自然かどうかは、別途 adapter /
proxy-certificate 側の義務である。

一つ目は visible-state route である。source/target の current-view
injectivity が extensionality を供給し、global current-view response-image
equivalence が local current-view equivalence に畳まれ、target 側の scoped
additive `L/M` separation entrance に入る。

二つ目は folded current-view skeleton surface である。同一計算条件は

```lean
CurrentViewObservationalSameCalculation
```

であり、これは観測語彙のみで書かれ、current-view fixed action coverage と
定義的に同値である。この scope、response separation、target identity、
initial current view の一致のもとで、source と alternative の
`CurrentInevitabilitySkeletonInterface` が構成され、
`SameCurrentSkeletonSurface` が証明される。

安全な読み:

```text
指定された visible/current-view same-calculation scope では、interface は
隠れた入力ではない。計算は出力 F/K/V_K skeleton を通り、scoped L/M
separation surface に入り、生成された二成分 trace が整合する。
```

これは現在の scoped semantic G1 spine である。ただし次は主張しない。

- すべての表現に対する scope-free semantic no-alternative;
- 任意の hidden-state system からの automatic adapter discovery;
- full native `L/B` recovery や qualified-support `M` measurement;
- 経験的予測または世界予測;
- 外部ドメインの native theorem reproof;
- 根拠なし外部ドメイン転用。

完全な研究 archive には、古い status/readout capstone や public wrapper が
残っている。それらは監査基盤としては有用だが、この curated core repository
には含めず、現在の semantic core の主引用対象でもない。現在の G1 proof
substance を引用するなら、上の二つの Lean アンカーを優先する。
